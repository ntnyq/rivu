## Close the window. Keep downloading.

Leave transfers in the background and check speeds and progress from the menu bar. Pause the queue, switch limits, or add a download whenever you need to. Quitting the app saves the session and stops transfers.

## Start with your first download

1. **Add a source**: open a torrent file or paste a magnet link.
2. **Choose your files**: preview the contents, set priorities, and pick a destination.
3. **Start the transfer**: follow progress in the main window or menu bar.

[Read the getting started guide →](guide/getting-started.md)

::: info Current availability
Rivu supports macOS 12 or later, Windows 10 / 11, and Linux. Download the package for your system from [GitHub Releases](https://github.com/ntnyq/rivu/releases), or build from source. See [Get started](guide/getting-started.md) for installation and Linux dependencies. New release builds support signed updates from GitHub Releases. Apple Developer ID signing and notarization are still being prepared.
:::

## Speaks your language

The app supports **English, 简体中文, 繁體中文, 日本語, and 한국어**. It follows your system language, with a manual choice in Settings.
