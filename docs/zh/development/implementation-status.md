# 实现状态

记录日期：2026 年 10 月 13 日。范围：以 macOS 为首要平台的 Rivu 0.0.1 开发构建。

## 已实现

应用已具备真实的应用级种子会话、原生主窗口/设置/导入/菜单栏视图、中文界面、设置和任务持久化、队列准入、文件优先级、暂停与批次恢复、重新校验、比例做种、完成通知记录、保守的私有磁力发现、根目录约束存储和日志式移除。产品标识、仓库与域名链接、可编辑和生成的图标也已配置。

视觉实现采用：191 pt 侧边栏、实心蓝色导航、69 pt 工具栏、102 pt 任务行、271 pt 详情栏、分段标签、文件符号和小号辅助文本。设置使用 168 pt 分类侧边栏、分组行与开关。测试渲染了两种外观和 880 × 560 最小窗口。

引擎固定为 anacrolix/torrent v1.61.1-0.20260927071845-d913b30f520e。本地受控 swarm 验证 v1、纯 v2 和混合种子的字节完整性、只读取磁力元数据而不写入内容、暂停分离、恢复校验以及跨共享分片的选择性下载。适配器保留 v1.61.0 引入的短哈希准入路径，在内容准入前由 Rivu 比较完整身份。未修改依赖缓存源码。

10 月 13 日重构增加独立磁力预览、结构化恢复提示、带宽单位、明确做种模式、已有数据接管、目录重定位、文件树和目录优先级、Tracker 诊断、定时限速、累计做种时长、任务标签和可选监视文件夹。详见[源码结构](implementation-structure.md)与[功能语义和验证](refactor-validation.md)。

## 已执行验证

- Go 单元/UI 测试、竞态检测、Go vet 和 MyGo vet。
- 主窗口默认/最小尺寸、设置、导入与菜单栏的浅色/深色 UI 渲染截图。
- 使用生成的合法测试数据运行本地 swarm，不依赖公共 Tracker。
- macOS arm64 应用构建、ad-hoc 签名、独立数据目录的原生启动/捕获/正常退出。交互检查涵盖设置、更新不可用提示、模态 sheet、无效磁力拒绝和 Cmd+Q。
- SVG 生成的 PNG 16–1024、macOS ICNS/iconset、Windows ICO 与模板托盘图标。

## 尚待满足的发布条件

此记录不表示所有里程碑的硬件验收均已通过，原始计划仍是验收参考。

- 已配置 GitHub Releases 更新源与内置验证公钥，发布构建要求匹配的 Actions 签名密钥，并在创建标签前校验签名更新包。macOS 通用包已通过临时应用包测试：错误签名保留旧应用，有效更新替换应用并成功启动新可执行文件。公开 Release 分发、完整设置/会话/重启流程及 Windows/Linux 原生更新仍需验收。正式 Developer ID 签名与公证仍未配置。
- macOS 登录/通知的详细授权适配器、多显示器面板、VoiceOver 及权限拒绝/撤销流程仍需打包后的原生验收。
- 各持久化和废纸篓边界的强制终止注入仍待扩展，大列表测量和基准见[重构报告](refactor-validation.md)。
- 崩溃后上传统计最多落后一个检查点区间。会话错误锁是运行时观测；手动暂停持久保存，环境错误在准入时重新探测。
- macOS/Linux 原子替换同步文件和父目录；重命名后同步失败会阻止修改，直到重新加载。断电恢复仍需针对文件系统验收。
- Windows amd64 和 Linux amd64 已通过交叉编译，但仅作为编译检查。Windows 已补齐基于句柄的内容归属、空间及禁止覆盖发布适配器，文件系统和传输仍需原生验收，见[桌面验收](desktop.md)。
- 此实现记录未执行 DNS/网站部署、仓库推送或 GitHub 发布，Rivu 自有代码尚未选定许可证。

以上验证与缺口对应记录日期，不是对后续依赖变更的自动验收。分发前请阅读[桌面验收](desktop.md)和[发布指南](releasing.md)。
