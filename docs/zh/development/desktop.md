# 桌面行为与验收

## 已实现路径

- MyGo 原生主窗口、设置和添加窗口；macOS 保留内嵌一体化标题栏，Windows/Linux 使用默认原生装饰，业务控件位于标题栏下方。
- 左键菜单栏浮出面板和临时右键菜单；Linux 回退为托盘菜单。
- Windows 双击托盘图标会恢复并聚焦主窗口，窗口已关闭时会重新创建。单击在系统双击间隔结束后打开浮出面板；右键会取消待执行的单击操作。禁用或重建托盘也会取消待执行的点击。
- macOS 通过 Dock 激活重新打开主窗口；Windows/Linux 仅在托盘创建成功时于关闭窗口后保留会话，否则关闭最后窗口会进入正常退出确认和保存流程。
- `mygo.json` 注册 `.torrent` 与 `magnet` 关联，初始化前到达的打开事件先排队。
- 第二实例参数复用导入预览；`--config` 不隔离应用身份。
- 登录注册使用 MyGo `SetOpenAtLogin`，打开设置时读取布尔状态；仅在存在 Dock/托盘恢复入口时，后台登录启动才保留会话而不显示窗口。
- 通知使用任务/完成周期 ID，点击定位任务；展示请求成功不等于实际送达。
- 睡眠前保存并停止活动，唤醒后按未改变的持久意图重新协调。
- 退出确认和异步保存也保护更新后的重启。

## 平台策略

- Windows/Linux 在文件菜单中提供设置、关于和退出，快捷键提示使用 Control。保存托盘偏好后会立即生效，无需同时切换语言；macOS 保留现有应用菜单和 Command 提示。
- `internal/netproxy` 为更新和传输共用环境变量／Windows 系统代理选择。HTTP Tracker 和 TCP 节点在新连接时解析路由，无需重启；TCP 使用 CONNECT 或 SOCKS5，DHT／UDP Tracker 保留系统路由。本地代理 swarm 测试覆盖节点发现和完整文件传输；Windows 实机的系统代理／TUN 切换及代理服务商的 BT 策略仍需验收。
- 新默认下载目录读取 Windows Known Folders 或 Linux XDG 用户目录，已保存的目录保持不变。导入预览和监控文件夹导入仅在下载父目录已存在时，自动创建当前或旧版 Rivu 默认目录；不会重建缺失的父目录或重定向卷。
- Windows 在接纳任务前检查设备保留名称、非法字符及控制字符。文件归属使用打开句柄查询卷序列号和完整 128 位文件 ID；无法提供该查询的文件系统会被拒绝。发布使用相对目录句柄的 NT 重命名，并禁用覆盖。Unix 所有权日志保留原有 ID 格式。
- 发布前会刷新文件和所有权日志内容。Windows 没有非特权目录 fsync 的等价操作，断电后的元数据持久性仍取决于文件系统。
- `TestPlatformWindowDecorations` 保护平台配置及 macOS 原有几何参数；`TestNativeTitleBarContentBounds` 覆盖五种语言、正常/最小宽度及侧栏展开/折叠。存储测试检查身份稳定、接管现有文件、拒绝覆盖、父目录重命名后的句柄锚定，以及缺失父目录保护；废纸篓操作复用路径组件校验和句柄身份，不再比较规范路径的文字拼写。CI 除 macOS 完整检查外，也在 Windows/Linux 运行存储、会话和本地 swarm 测试。

原生验收还须覆盖 Windows 跨屏 DPI、最大化/恢复、贴靠布局、窗口图标、拖动区域、模态焦点、长路径/UNC 和网络卷；Linux 须覆盖 GNOME/KDE 的 Wayland/X11、左/右/无标题栏按钮、分数缩放、缺少 AppIndicator 支持、托盘恢复、桌面关联及安装后集成。托盘创建成功不代表 Linux 桌面实际显示了图标，还须检查桌面托盘宿主或扩展。软件快照和交叉编译不能证明这些行为。

## 本地验证

开发 macOS arm64 主机已完成 ad-hoc 签名打包、隔离目录启动、原生空窗口渲染和通过保存协调器退出。MyGo 软件渲染截图覆盖默认/最小尺寸、两种外观、设置、导入和菜单栏，演示任务仅存在于测试中。原生交互还验证了添加下载实际呈现为 macOS sheet、无效磁力不会提交、设置可打开、未配置更新显示不可用，以及 Cmd+Q 正常退出。

## 视觉一致性

即使 AppKit 报告 vibrancy，菜单栏内容也使用设计配色。高度随最多四行预览变化（含已暂停任务），空状态为紧凑的 304 pt。暂停和限速位于底部操作区上方，添加下载、设置与打开主窗口并列。主任务行间距 102 pt，顶部对齐控件为 23 pt，拖放提示位于列表下方。

`make snapshots` 包括 1280 × 818 对照尺寸、空/有任务菜单栏以及两种外观的原生材质渲染路径。`TestTrayLayoutAndMaterial` 检查材质不透明度与底部边界。

语言默认跟随系统。通用设置提供简体中文、繁体中文、英语、日语和韩语，保存后生效。`TestLocalizedSurfaces` 覆盖全部语言的正常和最小窗口，并检查托盘操作边界。`make snapshots` 输出 `i18n-<language>-<surface>.png`。词条测试检查覆盖和格式占位符，设置测试覆盖语言迁移与保存。

2026 年 10 月 17 日，本地化迁移到 MyGo v0.5.5 的 ARB 词条、生成的类型化函数和应用语言回调。单元测试、Go vet、竞态、本地 swarm、MyGo vet、词条检查及多语言快照均通过。macOS arm64 应用构建成功，五种语言的打包资源由词条生成。七个隔离原生会话完成启动、截图和退出，覆盖五种语言的主窗口、日语下载设置和繁体中文托盘，截图为 `snapshots/native-mygo-i18n-*.png`。另一个隔离会话验证英语 → 日语 → 跟随系统的实际保存切换，菜单、窗口标题、已有主窗口及保存结果即时刷新；`MYGO_LOCALE` 防止测试写入原生语言偏好。

2026 年 10 月 12 日，macOS arm64 本地化构建完成五种显式语言及系统默认的原生启动/捕获/退出检查。通过独立数据目录和 `XDG_RUNTIME_DIR` 隔离实例套接字，使已安装应用保持运行。当时自动化服务在交互保存切换检查中超时，因此该项保留为验收要求；已有窗口的语言刷新由无界面 UI 测试覆盖。

```sh
  build/darwin-arm64/Rivu.app/Contents/MacOS/Rivu --data-dir /tmp/rivu-tray-review
```

此命令捕获原生内容；系统绘制的箭头、外部圆角、阴影和多显示器定位仍需交互检查。
