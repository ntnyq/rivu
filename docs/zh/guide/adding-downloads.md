# 添加下载

Rivu 支持 `.torrent` 文件与磁力链接，包括 v1、纯 v2 和混合种子。

## 打开种子文件

选择 **添加下载**（**⌘N**）、使用 **打开种子文件**（**⌘O**），或将种子文件拖入主窗口。也可以通过系统的打开方式，将种子或磁力链接交给 Rivu。

选择保存位置，点击 **读取并预览**，检查内容后再添加任务。需要整理时，可以在预览窗口为新任务添加标签。

## 预览磁力链接

在 **添加下载** 中粘贴磁力链接，点击 **读取并预览**。Rivu 会获取元数据，让你在开始前检查种子名称、大小与文件树。

- 预览不会向下载目录写入文件内容。
- 可以取消或重试；关闭添加窗口也会取消预览。
- 无法解析元数据时，预览会在 45 秒后超时。

在元数据确认种子是否私有之前，Rivu 只使用链接中明确提供的 Tracker 或对等节点；两者都没有的链接会被拒绝。Rivu 不会抓取任意元数据来源 URL 或 Web Seed。

解析失败时，检查链接来源与网络连接，再按[故障排查](troubleshooting.md)中的步骤处理。

## 选择文件与优先级

在文件树中展开目录、搜索文件名，为文件或整个目录选择 **高**、**普通** 或 **跳过**。至少保留一个选中文件，大文件列表会分页显示。

跳过的文件仍可能占用少量磁盘空间：相邻文件可能共享种子分片，完成选中文件时可能需要写入其中部分数据。

任务开始后，仍可在详情面板中调整文件优先级。

## 复用已有文件

新下载应使用没有冲突文件的位置。要从已有数据继续：

1. 选择包含种子顶层名称的目录。
2. 启用 **接管并校验已有文件**。
3. 检查预览并添加任务。

任务运行时，Rivu 会校验数据并补齐缺失或损坏的分片。移除任务时会保留接管的文件，也无法通过 Rivu 将它们移到废纸篓。

需要修改现有任务目录时，使用[修改位置](troubleshooting.md#下载目录发生变化)。该操作更新任务指向的位置，不会替你搬移文件。
