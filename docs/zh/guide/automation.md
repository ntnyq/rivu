# 自动化

## 使用标签整理任务

在任务详情面板中输入以逗号分隔的标签，再通过工具栏标签筛选查找相关传输。添加下载时，也可直接在预览窗口分配标签。

例如，用 `linux, images` 整理系统镜像，用 `archives` 整理数据归档。

## 定时限速

1. 打开 **设置 → 自动化**。
2. 启用每日限速区间。
3. 以 `HH:MM` 格式输入开始和结束时间，使用本地时间。
4. 配置临时上传与下载限制并保存。

支持跨午夜，例如 **22:00–08:00**。区间内，Rivu 使用临时限速值。

手动限速开关使用同一组临时限制。开启后可在定时区间外继续限速；在定时区间内关闭手动开关，定时规则仍然生效。需要在区间内恢复普通限制时，请关闭定时规则。

定时规则不会恢复手动暂停的任务。

## 监视文件夹并导入

1. 打开 **设置 → 自动化**，启用 **监视文件夹**。
2. 输入文件夹的绝对路径。
3. 按需设置自动标签。
4. 保存设置，将 `.torrent` 文件放入该文件夹。

Rivu 每 10 秒检查一次，连续两次扫描内容一致后才会导入。新任务使用默认下载目录。

监视文件夹的行为如下：

- 只导入该目录内的普通 `.torrent` 文件，不扫描子目录。
- 保留原始种子文件。
- 已导入且内容未变化的文件不会重复出现，即使已移除任务或重启应用。
- 无效文件保留以供修正，不影响其他导入。
- 不会自动接管有冲突的下载数据。

种子没有出现时，请检查监视功能是否启用、目录是否可访问、文件是否写入完成，以及下载位置是否有冲突数据。复用已有文件时，请[手动添加并接管](adding-downloads.md#复用已有文件)。
