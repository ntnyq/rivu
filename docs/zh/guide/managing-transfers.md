# 管理传输

## 查找任务

通过侧边栏筛选下载中、做种中、已完成、已暂停或需要处理的任务。可以搜索、排序队列，也可使用标签筛选进一步缩小范围。

选择任务后，详情面板会展示进度、文件树与连接信息。连接页包含对等节点数量、Tracker 通告结果、失败原因，以及引擎提供的下次通告时间。诊断信息每五秒刷新一次。

## 暂停与恢复

使用任务上的操作暂停或恢复单个传输。需要暂时停止一批任务时，选择 **全部暂停**，之后使用 **恢复暂停批次**。

恢复批次会保留之前已单独暂停的任务。手动暂停和最近一次暂停批次在重启后仍然保留。

## 限制带宽与并发数

在 **设置 → 下载与做种** 中配置上传、下载限制，以及最大并发下载数。普通带宽限制支持 KB/s 或 MB/s，**0 表示不限速**。

使用限速开关启用临时限制。需要按每天的安排限速时，请阅读[定时限速](automation.md#定时限速)。

## 选择做种策略

做种会将已下载的分片分享给其他节点。在 **设置 → 下载与做种** 中选择默认策略，也可在任务详情面板单独覆盖。

| 策略         | 行为                                 |
| ------------ | ------------------------------------ |
| 完成后停止   | 选中文件下载完成后停止。             |
| 目标分享率   | 上传量与下载量的比值达到目标后停止。 |
| 不限分享率   | 持续做种，不设分享率上限。           |
| 可选时长限制 | 累计有效做种时间达到设定值后停止。   |

时长限制可以与分享率策略配合使用，计算的是实际做种时间，不是从导入任务起经过的总时间。

## 在后台继续下载

关闭主窗口后，Rivu 和传输会继续运行。通过菜单栏面板查看速度与活动任务、暂停传输、切换限速、添加下载或重新打开窗口。

退出 Rivu 会保存会话并停止传输。恢复时会重新校验已下载数据，而不是直接采用保存的百分比。

## 移除任务

移除任务**默认保留下载文件**。移到废纸篓是独立选项，仅适用于记录为该任务所有的文件；接管的已有文件会保留在磁盘上。

如果移到废纸篓的操作部分失败，Rivu 会记录已完成的步骤并提示问题，不会改为永久删除。重试前请阅读[故障排查](troubleshooting.md)。
