# 设置与快捷键

按 **⌘,** 打开设置，修改后保存即可应用。

## 外观与语言

在 **通用** 中选择浅色、深色或跟随系统外观。Rivu 支持**英语、简体中文、繁体中文、日语和韩语**。

语言默认跟随系统偏好，无法匹配时使用英语。选择其他语言并保存后，界面与原生菜单立即更新；系统对话框和第三方诊断信息可能使用各自的语言。

## 下载与做种

在 **下载与做种** 中选择默认保存位置、并发下载数、普通与临时带宽限制，以及默认做种策略。

初始下载目录是 `~/Downloads/Rivu`，添加任务时可以单独选择其他位置。修改默认目录不会搬移已有下载；现有任务请使用[修改位置](troubleshooting.md#下载目录发生变化)。

带宽与做种行为见[管理传输](managing-transfers.md)，定时规则与文件夹监视见[自动化](automation.md)。

## 更新

在 **更新与关于** 中点击 **检查更新**，即可检查 GitHub Releases 最新公开稳定版。新版发行构建会使用内置公钥验证下载的更新包，校验通过后才替换应用。草稿版本不会推送给用户。

自动检查与自动安装默认均关闭。启用自动检查并保存后，应用大约每天检查一次；自动安装需要单独启用，并等待传输会话空闲，包括没有活跃做种。安装后点击 **保存并重启**，应用不会在传输期间自动重启。

应用必须安装在可写位置：macOS 请先复制到“应用程序”，不要直接从 DMG 运行。Linux DEB 安装应通过包管理器更新；`install.sh` 的用户目录安装在目录可写时支持应用内更新。开发模式和未配置更新源的旧版本会显示**不可用**，这不代表已经是最新版；旧版本需要先手动安装一次支持更新的发行版。

## 键盘快捷键

下表使用 macOS 按键符号；Windows 和 Linux 请将 **⌘** 替换为 **Ctrl**。

| 快捷键 | 操作            |
| ------ | --------------- |
| ⌘N     | 添加下载        |
| ⌘O     | 选择种子文件    |
| ⌘1     | 打开主窗口      |
| ⌘K     | 打开命令面板    |
| ⌘,     | 打开设置        |
| ⌘Q     | 保存并退出 Rivu |

也可以通过命令面板查找应用操作。**传输**菜单提供全部暂停、恢复暂停批次和切换限速等命令。

## 数据保存位置

偏好设置和会话数据使用系统配置目录：

| 系统    | 默认位置                                             |
| ------- | ---------------------------------------------------- |
| macOS   | `~/Library/Application Support/Rivu`                 |
| Windows | `%AppData%\Rivu`                                     |
| Linux   | `$XDG_CONFIG_HOME/Rivu`，未设置时为 `~/.config/Rivu` |

下载文件保存在每个任务选择的位置。

备份与恢复见[故障排查](troubleshooting.md#备份或修复会话)，开发时可用[启动选项](../development/index.md#启动选项)覆盖存储位置。
