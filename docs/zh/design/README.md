# Rivu 界面原型

此原型仅用于评审，配合[产品设计](../product-design.md)阅读。应用继续使用 Go + MyGo 原生 UI；这里的 HTML、CSS 和 JavaScript 不代表应用迁移到 Web 前端。

原型界面文案为中文。站点文档提供中英文版本。

## 打开原型

在仓库中使用浏览器直接打开 `docs/design/index.html`，所有资源均在本地，无需构建或安装依赖。也可从仓库根目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory docs/design
```

然后打开 `http://127.0.0.1:8765`。[查看原型源码](https://github.com/ntnyq/rivu/tree/main/docs/design)。VitePress 站点展示原型说明和图片，交互原型通过上述本地方式运行。

## 评审流程

- 顶部场景按钮切换主窗口、菜单栏、添加下载 sheet 和设置。
- 筛选、搜索、排序，选择任务查看概览、文件与连接。
- 暂停/恢复任务，观察列表、总速率与面板同步。
- 在面板全部暂停后恢复该批次，原本已暂停的任务保持暂停。
- 切换临时限速，关闭模拟主窗口并从面板重新打开。
- 添加示例种子、选择文件和位置，再次添加观察重复处理。
- 移除任务时检查独立且默认未选中的文件移除选项。
- 检查启动、通知、连接和更新设置，预览更新可用、未配置和失败状态。
- 切换浅色/深色，用底部按钮检查空状态、错误状态及重置示例任务。

## 边界

原型不下载数据、不读剪贴板、不修改登录项、不发送真实通知、不打开 Finder、不安装更新也不删除文件。示例磁力和 Tracker 都是不会实际解析的测试数据。

种子选择器模拟选择示例。任意磁力链接会被拒绝，因为未实现元数据读取。菜单标签及黄色/绿色窗口按钮仅为展示。多选、真实拖放、可编辑文件优先级和原生对话框属于设计要求，在该原型中未实现。

设置和任务仅在内存，刷新即重置。重置按钮恢复任务样本，但不重置全部设置。勾选登录启动后才启用仅后台启动选项，设置只展示状态，不修改操作系统。

布局目标使用原生点数，浏览器仅近似展示。原生材质、字号、辅助功能和窗口行为仍需在 macOS MyGo 应用中验证。

## 文件

| 文件         | 用途                     |
| ------------ | ------------------------ |
| `index.html` | 应用外壳与对话框         |
| `styles.css` | 两种外观与自适应评审布局 |
| `app.js`     | 内存示例状态与交互       |
| `previews/`  | 评审截图                 |

使用系统字体和本地矢量符号，不请求外部资源或应用 API。
