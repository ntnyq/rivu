# 使用 Rivu

[文档首页](index.md) · [构建与运行](development.md)

Rivu 是正在开发中的 macOS BitTorrent 下载器，支持 `.torrent` 文件和磁力链接，包括 v1、纯 v2 与混合种子。

## 添加下载

选择 **添加下载**，将种子文件拖入主窗口，或使用 Rivu 打开种子文件和磁力链接。检查来源并选择保存位置，点击 **读取并预览** 解析元数据，再检查名称、大小与文件树后提交任务。磁力预览不会向目标目录下载文件内容，45 秒后超时，支持取消与重试；关闭添加窗口也会取消预览。

新下载应使用没有冲突文件的目录。要复用现有数据，请明确选择 **接管并校验已有文件**。任务运行时会校验内容并修复缺失或损坏的分片。接管文件始终不会获得移到废纸篓的权限，移除任务时会保留它们。未选择接管时，冲突文件会导致导入被拒绝。

在元数据确认种子是否为私有种子前，未解析的磁力链接仅使用明确提供的 Tracker 或对等节点；两者都没有的磁力链接会被拒绝并显示原因。Rivu 不会抓取任意元数据来源 URL 或 Web Seed。

## 管理传输

通过侧边栏筛选下载中、做种中、已完成、已暂停或需要处理的任务。搜索和排序列表，选择任务查看进度、文件与连接信息。

文件树支持展开目录、搜索和整目录修改优先级，大文件列表使用分页。优先级包括高、普通和跳过，至少保留一个选中文件。文件之间可能共享种子分片，因此跳过的文件仍可能包含完成相邻选中文件所需的数据。

在 **设置 → 下载与做种** 中配置并发下载数和带宽限制。速率使用 KB/s 或 MB/s，普通限制为 0 表示不限速。做种可选择完成后停止、达到目标分享率后停止或不限分享率，并可附加累计有效做种小时数。详情面板可覆盖单个任务的做种策略。

可以暂停或恢复单个任务，也可以 **全部暂停** 后 **恢复暂停批次**。恢复批次会保留先前已手动暂停的任务。手动暂停与最近一次暂停批次在重启后仍然保留。

关闭主窗口后，应用和传输继续运行。菜单栏面板可查看速度、暂停任务、切换限速或重新打开主窗口。退出 Rivu 会保存会话并停止传输。

移除任务默认保留文件。移到废纸篓是独立选项，仅作用于记录为该任务所有的文件。部分操作失败时会记录已完成步骤，绝不会改为永久删除。

## 标签、定时限速与监视文件夹

在任务详情面板中编辑以逗号分隔的标签，然后用工具栏标签筛选。导入预览也可为新任务添加标签。

在 **设置 → 自动化** 中启用每日本地时间限速区间，使用 `HH:MM` 格式，支持跨午夜。区间内使用临时上传与下载限制。手动慢速模式可在区间外继续使用这些限制；关闭手动慢速模式不会取消正在生效的定时限速。要在区间内恢复普通限制，需要关闭定时规则。规则不会恢复手动暂停的任务。

启用 **监视文件夹**，输入绝对路径和可选自动标签后保存。Rivu 每 10 秒检查该目录内的普通 `.torrent` 文件，连续两次扫描内容一致后自动导入默认下载目录。不递归扫描、不删除源种子，也不会自动接管冲突文件。持久化账本避免未变化文件在任务移除或应用重启后重复导入。无效文件保留以供修正，不影响其他导入。

## 外观与语言

支持浅色与深色外观，以及简体中文、繁体中文、英语、日语和韩语。

默认跟随系统首选语言，无法匹配时回退英语。在 **设置 → 通用 → 语言** 中修改并保存后，界面与原生菜单立即更新。系统对话框与第三方诊断信息可能使用各自的语言。

## 存储与恢复

macOS 上的应用数据通常位于 `~/Library/Application Support/Rivu`，即 `os.UserConfigDir()/Rivu`。其中包含 `settings.json`、`session.json`、不可变种子元数据及文件归属日志。监视文件夹账本位于配置文件旁，下载文件则存放在每个任务选择的目录。

恢复任务时会重新计算哈希，通过实际数据确认完成情况，不信任已保存百分比。上传总量和累计做种时间每 15 秒保存一次，强制终止可能丢失最后一个统计区间。

损坏文件或不受支持的较新数据版本会阻止修改，原文件保持不变。修复前请备份，之后选择 **文件 → 修复后重新加载会话与设置**。显式加载时可以迁移版本 1 设置；Rivu 不会改动其他产品的配置目录。

修复错误原因后可重试任务。磁盘或位置发生变化时，在详情面板选择 **更改位置…**，选中包含种子顶层名称的目录并确认。此操作不移动旧目录文件。新位置数据会在运行时校验，移除任务时予以保留；手动暂停的任务仍保持暂停。

连接页显示节点数量、各 Tracker 的通告状态、分类错误与引擎报告的下次通告时间，每 5 秒刷新。诊断行隐藏凭据。等待节点可能是正常情况，重试前请检查网络与 Tracker 结果。

会话格式会从版本 1 迁移至版本 2，保留任务和手动暂停意图。仅支持版本 1 的旧应用无法打开迁移后的会话。

自定义会话与设置位置见[启动选项](development.md#启动选项)。

## 当前可用性

仓库提供开发实现和本地 macOS 打包能力，尚未配置正式签名、公证和可信更新源。在提供可信发布配置前，更新检查会显示不可用。

Windows 与 Linux 构建仅用于编译检查，不是受支持的下载版本。原生权限、多显示器菜单栏、辅助功能、强制终止恢复和签名更新替换仍有待验收，详见[桌面验证](desktop.md)与[实现状态](implementation-status.md)。

产品域名的配置不代表已部署网站或 DNS，分发要求见[发布指南](releasing.md)。
